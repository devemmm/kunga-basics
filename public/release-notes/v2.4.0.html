🔐 Authentication
FEAT
Email verified before account creation
The registration flow was redesigned so a 6-digit OTP is sent to the user's email address before any account is created. The account is only written to the database after the user submits the correct code. This eliminates unverified or partial accounts and sets emailVerified = true at the moment of creation.
kunga-api kunga-user-portal kunga-mobile-app
FEAT
New endpoints: send & resend registration OTP
Two new API routes were added: POST /auth/send-registration-otp (step 1 — sends OTP, no account created) and POST /auth/resend-registration-otp. OTPs are stored in Redis with a 10-minute TTL and a 3-attempt lockout. The /auth/register endpoint now requires the otp field.
kunga-api
FIX
OTP "Create Account" button unresponsive on iOS
On iOS, tapping the button while the keyboard was open consumed the first tap to dismiss the keyboard instead of triggering the action. Fixed by removing the disabled prop dependency on code completeness — the button stays enabled, and validation happens inside the handler.
kunga-mobile-app
FIX
OTP verify button unresponsive on web portal
The PrimaryBtn component did not accept or forward the onClick prop, so the button rendered but never fired. The prop is now explicitly forwarded to the underlying <button> element.
kunga-user-portal
FEAT
OTP auto-submits when all 6 digits are entered
Both the web portal and mobile app now automatically trigger verification as soon as the sixth digit is typed or pasted. A verifyRef pattern is used to avoid stale closure bugs on auto-submit.
kunga-user-portal kunga-mobile-app
FIX
Google Sign-In button missing on production (web portal)
VITE_GOOGLE_CLIENT_ID was not being passed as a Docker build argument, so Vite baked an empty string into the bundle. The Dockerfile and docker-compose.yml were updated to pass it correctly at build time.
kunga-user-portal
📥 Book Download Tracking
FEAT
Track who downloads the free book and when
Every click of the "Download Free Book" button now records the user, timestamp, platform (web or mobile), and IP address in a new book_downloads database table. Tracking is fire-and-forget — it never blocks the actual download.
kunga-api kunga-user-portal kunga-mobile-app
FEAT
Book download statistics in Admin → Analytics
A new section was added at the bottom of the Analytics page showing: total downloads, unique downloaders, web vs. mobile breakdown, and a full paginated table of every download with the user's name, email, platform badge, and exact timestamp.
kunga-admin-portal
DEPLOY
DB migration included in deploy script
deploy.sh now runs a CREATE TABLE IF NOT EXISTS step automatically before the RBAC seed, so no manual SQL is needed. Running ./deploy.sh on the server is all that is required.

⭐ Subscription Plans
UPDATE
Clearer Gold vs. Premium differentiation
The Available Plans section was updated to make the value difference obvious to users. Gold now lists 6 features including Ask Dr. Gad (2 questions/mo). Premium lists everything in Gold plus unlimited expert questions, unlimited child assessments, priority support (24h response), downloadable milestone reports, and early access to new modules. A "⭐ Most Popular" badge was added to the Premium card to guide users toward it.
